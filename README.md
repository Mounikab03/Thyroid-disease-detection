# 🧠 Thyroid Disease Prediction Web App

This is a full-stack web application that predicts the **type of thyroid disease** based on user input using a **Random Forest Classification Model**.

---

## 🎯 Classes Predicted

The model can classify a patient into one of the following **five thyroid disease types**:
- Negative
- Primary Hypothyroid
- Secondary Hypothyroid
- Compensated Hypothyroid
- Hyperthyroid
